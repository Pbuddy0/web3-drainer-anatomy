# Security & Responsible Use Policy

## Purpose of this repository

This project documents **how Web3 wallet-draining attacks work** so that developers,
auditors, and end users can recognize and defend against them. It is published for
education and defensive research.

## What we will not publish

- Working drainer kits, lure pages, or relay infrastructure deployable against real users
- Mainnet configurations, funded keys, or instructions for attacking systems you don't own
- Anything whose primary value is offensive rather than educational

Contributions that cross this line will be declined regardless of technical quality.

## If you find a problem in this repo

If content here is factually wrong, could be weaponized more easily than intended, or
infringes your rights:

- Open a [GitHub issue](../../issues) for factual corrections and improvements, **or**
- For sensitive reports (e.g., something here enables abuse), email the maintainer via the
  address on the GitHub profile rather than opening a public issue.

## Testing ethics reminder

If you reproduce any technique described here to learn, do it **only** on Sepolia/testnet,
against wallets and contracts you control. Using these techniques on mainnet or against other
people's wallets is theft and computer fraud in most jurisdictions.
